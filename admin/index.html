Publicar
Guardá los cambios en GitHub para que todos los vean.

Listo para publicar

Los cambios se suben directo al repositorio de GitHub

¿Cómo funciona?
1

Editás el contenido en las secciones del panel.

2

Apretás Publicar cambios (arriba a la derecha o el botón de abajo).

3

El admin sube el archivo content.json directamente a tu repositorio de GitHub.

4

GitHub Pages se actualiza automáticamente en ~30 segundos. Todos los visitantes ven los cambios.

Los cambios estarán visibles en el sitio en aproximadamente 30 segundos.
Configuración
Conectá el admin con tu repositorio de GitHub. Se hace una sola vez.
¿Cómo obtener el Token de GitHub?
1. Entrá a github.com → tu foto → Settings
2. Bajá hasta Developer settings → Personal access tokens → Tokens (classic)
3. Click en Generate new token (classic)
4. Poné un nombre (ej: "SAZ Admin"), seleccioná el scope repo y generalo
5. Copiá el token y pegalo abajo — solo se muestra una vez
